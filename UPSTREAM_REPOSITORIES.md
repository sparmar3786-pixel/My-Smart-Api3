## Status definitions
- **Partially vendored:** some upstream source files and required license/notice/import notes are in `vendor/`; not the complete upstream repository.
- **Adapted/original code:** new compatible implementation in this repo, not copied verbatim.
- **Reference only / pending review:** URL recorded; source files, license, dependencies, security and compatibility are not fully reviewed.
- **Blocked:** source is inaccessible or redistribution permission is unclear for the intended use.

See `UPSTREAM_AUDIT.md`, `COPY_STATUS.md` and `INTEGRATION_GUIDE.md`. Do not commit API keys, passwords, MPINs, TOTP seeds, JWTs, feed tokens or account secrets.
